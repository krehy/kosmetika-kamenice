# Studio Kamenice

Jednostránková webová prezentace kosmetického studia **Studio Kamenice** v Kamenici nad Lipou.

## Co tu je

- `index.html` — kompletní stránka (HTML + CSS + JS v jednom souboru)
- `assets/hero-scrubbable.mp4` — scroll-scrubbed hero video (re-encoded pro plynulý scrub)
- `assets/hero.mp4` — zdrojové hero video
- `assets/poster.jpg` — poster frame zobrazený než se video načte

## Lokální spuštění

```bash
python3 -m http.server 8765
```

Otevři http://localhost:8765

## Deploy

Hostováno přes **GitHub Pages** — každý push na `main` se automaticky publikuje.
